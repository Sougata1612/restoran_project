# 🍽️ Restoran Management System

A full-stack Restaurant Management System developed using **HTML, CSS, JavaScript, PHP, and MySQL**. The application helps restaurant staff efficiently manage customers, menu items, orders, billing, and overall restaurant operations through a simple and user-friendly interface.

---

## 🚀 Features

- 🔐 Secure user authentication
- 🍕 Menu management (Add, Update, Delete menu items)
- 🛒 Customer order management
- 🧾 Billing and invoice generation
- 💰 Order total calculation
- 📋 Customer information management
- 📊 Admin dashboard
- 🔍 Search and filter functionality
- 📱 Responsive user interface

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/Sougata1612/restoran_project.git

cd restoran_project
```

---

## Database Setup

1. Create a MySQL database.

2. Import the SQL file.

```sql
database.sql
```

3. Update database credentials in `config.php`.

```php
$host = "localhost";
$user = "root";
$password = "";
$database = "restaurant_db";
```

---

## Run the Project

Move the project folder into your XAMPP/WAMP `htdocs` directory.

Start:

- Apache
- MySQL

Open your browser:

```
http://localhost/restoran_project
```
